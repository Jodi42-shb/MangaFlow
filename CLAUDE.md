## High‑Level Architecture Overview

The project is a pipeline that translates Japanese manga panels into English while preserving visual layout. The core flow is orchestrated in `main.py` and consists of the following stages:

1. **Configuration (`manga_translator/config.py`)** – defines paths (`IMAGE_DIR`, `TRANSLATED_DIR`, `MODEL_PATH`, `FONT_PATH`).
2. **Image Pre‑processing (`manga_translator/image_utils.py`)** – normalises image files and prepares them for detection.
3. **Text Region Detection (`manga_translator/detection.py`)** – loads a YOLO model (`load_yolo_model`) and returns bounding boxes for text bubbles (`detect_text_regions`).
4. **OCR (`manga_translator/ocr.py`)** – uses `MangaOcr` to extract raw Japanese text and validates results (`validate_ocr_result`, `verify_japanese_text`).
5. **Text Cleaning & Sentence Splitting (`manga_translator/text_utils.py`)** – normalises OCR output (`clean_ocr_text`), splits into sentences (`split_japanese_sentences`).
6. **Translation (`manga_translator/translation.py`)** – a local NLLB‑200 model (`LocalNLLBTranslator`) translates cleaned sentences; post‑processes with manga‑style formatting.
7. **Overlay (`manga_translator/overlay.py`)** – inserts translated text back into the image, dynamically adjusting font size and wrapping (`insert_translation`, `check_and_fix_truncated_text`).
8. **Output** – saves translated images to `translated_images/` and creates side‑by‑side comparison PNGs.

## Development Tips for Claude Code
- When adding or modifying functionality, locate the relevant stage above and edit the corresponding module.
- New Python dependencies must be added to `requirements.txt` and installed with the setup command.
- The code expects a YOLO model file (`best.pt`) at the repository root; ensure this is present before running.
- Fonts are loaded from `font/CC Wild Words Roman.ttf`; if the file is missing, the overlay falls back to the default PIL font.
- For quick experimentation on a single image, modify `IMAGE_DIR` in `config.py` or set the environment variable before invoking `python main.py`.
